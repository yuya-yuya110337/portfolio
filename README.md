# Portfolio

## 🌐 概要
このリポジトリは、個人ポートフォリオサイトのソースコードです。  
HTML・CSS を中心に構築し、作品紹介や自己紹介ページを含んでいます。

## 🧩 使用技術
- HTML5 / CSS3  
- GitHub Pages（公開用）  
- VSCode（開発環境）

## 🚀 公開方法
GitHub Pages を利用して公開しています。  
リポジトリ設定の「Pages」から `main` ブランチを選択すると自動的に公開されます。
